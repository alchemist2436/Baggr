# BaggrAI - Repaired Version (Python 3.13 Compatible)

✅ Replaces broken gcloud with google-cloud-storage  
✅ Uses pyrebase4 for auth  
✅ Connects securely to Firestore with firebase-admin  

## How to Run:
1. Replace Firebase config in app.py  
2. Add firebase_key.json in the same folder  
3. `pip install -r requirements.txt`  
4. `streamlit run app.py`
